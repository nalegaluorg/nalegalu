1. Strony podkreślają konieczność odbywania konsultacji pomiędzy Ministerstwami Spraw Zagranicznych. Celem konsultacji będzie dokonanie oceny stosunków bilateralnych oraz wymiana poglądów na temat spraw regionalnych międzynarodowych, szczególnie odniesieniu do kwestii będących przedmiotem dyskusji na forach organizacji
2. Islamska Republika Afganistanu wyraża głęboką wdzięczność za zaangażowanie Rzeczypospolitej Polskiej, szczególnie odniesieniu do jej obecności działań prowincji 3 S r o n y p o d r ś l j ą p o r b ę p r c p r p o ł c n o ś ć m ę d y n r o d o ą , y m ł c p ń r g o nu , u r y m n p r d m o r y c n ł d g o p ń b p c ń ł d u p o ł c n g o I l m j R p u b li c A f g n nu R c p o p o li l y r ż g o o o ś ć p r n y c h y ił ó r m c h o b o ą ń y n j ą c y c h j j c ł o n o o r g n c j c h m ę d y n r o d o y c h 4 o d o o , r n n p o r b y , S r o n y o b o ą u j ą ę d o p r p r o d n o n u l c ji m ę d y r ą d o y c h , ó r y c h c l m b ę d m ę d y y m m o c n n d ł ń l c rr o r y m m o r g n o n ą p r ę p c o ś c ą l S r o n y b ę d ą p r ć d u r o ą p ó ł p r c ę g o p o d r c ą , c g ó l n o ś c p o p r f y n p r o m o n d ł l n o ś c p o l c h p r d ę b o r c ó I l m j R p u b li c A f g n nu o r f g ń c h R c y p o p o li j l j 2 S r o n y p o d r ś l j ą p o r b ę ę n o b r o ó h n d l o y c h o u n c h b l r l n y c h zobowiązują się do rozważenia uruchomienia dodatkowych narzędzi wspierających realizację tego zadania.
3 S r o n y p o d j m ą d ł n m j ą c n c l u ę n p o l o - f g ń j p ó ł p r c y gospodarczej, szczególnie sektorach: wydobywczym, rolniczo-spożywczym, usługowym o r b u d o n c , p o p r o r g n o n c y li c n y c h , b il r l n y c h p o ń umożliwiających nawiązanie kontaktów o charakterze gospodarczym.
4 S r o n y p o d r ś l j ą , ż ę n b il r l n j p ó ł p r c y g o p o d r c j y m g , b y Islamska Republika Afganistanu dołożyła wszelkich starań na rzecz kształtowania środowiska przychylnego rozwojowi biznesu inwestycji, ze szczególnym uwzględnieniem
5. Strony będą wspierać wzajemne inwestycje na swoich terytoriach zgodnie ż wewnętrznym
6. Strony rozważą podpisanie porozumienia o współpracy gospodarczej, zawierającego dalsze szczegóły dotyczące sposobów wsparcia rozwoju stosunków gospodarczych o charakterze l. Wspierając rozwój pełnej funkcjonalności państwa, Strony wyrażają poparcie dla budowy n y u c j o n l n y c h d o l n o ś c ł d f g ń c h y o r y n m p o ł c h d o ś d c ń transformacji ustrojowej, co powinno prowadzić do poprawy warunków życia Afgańczyków.
2. Wraz ze stopniową zmianą dotychczasowego charakteru zaangażowania związku r j ą c y m p r o c m p r j ś c o y m ( d o 2 01 4 r o u ) , j g o n ę p d ę c o l n m procesem transformacji, Rzeczpospolita Połska wyraża gotowość dalszego wspierania Islamskiej Republiki Afganistanu poprzez przekazywanie doświadczeń transformacyjnych o r u d ł n p o m o c y f g ń j l u d n o ś c r ó ż n y c h f o r m c h u g o d n o n y c h m ę d y S r o n m , r n n j p o r b y 3 S r o n y o b o ą u j ą ę d o p r p r o d n o n u l c ji d o c y li c n g o p r g l ą d u o b r ó aa n g ż o n R c y p o p o li j l j I l m j R p u b li c A f g n nu , b y o dp o d ł o o n o p o r b o m p o ł c ń f g ń g o W p ó ł p r c d d n d u c ji , n u u l u r y 1 ą ż ą c d o p o g ł ę b n o un ó b il r l n y c h d d n d u c ji , n u u l u r y , S r o n y r o ż ą p o dp n n o j u m o y , ó r ą p o b o ą u j ą c ą m o ę o W p ó ł p r c y K u l u r l n j m ę d y R ą d m l j R c y p o p o li j L u d o j R ą d m K r ó l A f g n nu , p o dp n ą K b u l u d n 25 c r c 1966 r o u
2. Strony wyrażają gotowość stworzenia instytucjonalnych relacji pomiędzy ich rządami r d u c ji p o p r n ą n p ó ł p r c y m ę d y ł ś c y m m n r m
3. Strony wyrażają zainteresowanie pogłębianiem współpracy zakresie nauki edukacji.
W tym celu popierają współpracę pomiędzy jednostkami naukowymi, organizacjami instytucjami państwowymi oraz pozarządowymi, szczególnie zakresie szkolnictwa
4. Strony popierają rozwój nauki języka polskiego Islamskiej Republice Afganistanu oraz języków dari pasztu Rzeczypospolitej Polskiej.
5. Strony wyrażają gotowość rozważenia możliwości wsparcia kształcenia zakresie szkolnictwa wyższego obywateli obu krajów, ramach istniejących krajowych mechanizmów finansowych oraz prawnych obszarach stanowiących zainteresowanie
6. Strony będą rozwijać współpracę dziedzinie ochrony dziedzictwa narodowego kulturowego, oraz podejmować wspólne projekty zakresie restauracji konserwacji zabytków, stopniu odpowiadającym potrzebom możliwościom Stron.
1. Niniejsza Umowa podlega przyjęciu zgodnie prawem wewnętrznym każdej ze Stron, co zostanie stwierdzone drodze wymiany not. Za dzień wejścia życie Umowy uważać się
2. Niniejsza Umowa będzie zarejestrowana Sekretariacie Narodów Zjednoczonych, zgodnie
3. Wszelkie zmiany do tekstu Umowy powinny być uzgodnione między Stronami formie pisemnej wejdąw życie trybie określonym ustępie 1.
4. Niniejsza Umowa zawarta jest na okres 15 lat. Jej ważność będzie przedłużana automatycznie na dalsze okresy pięcioletnie, o ile jedna ze Stron nie powiadomi drugiej Strony, pisemnie przynajmniej na rok przed wygaśnięciem kolejnego okresu ważności, o swojej decyzji
5.
